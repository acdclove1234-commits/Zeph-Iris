Zeph-Iris（ファン制御ツール。6.6.1 までの名前は ProFanController、6.7.0〜6.7.3 は Fanlume）
=========================================

マザーボードのファン端子を、温度に合わせて自動で制御するツールです。
温度・使用率の監視、冷却テスト、OpenRGB での LED の制御、スマホからの確認などもできます。
名前は、西風の神ゼピュロス（ファン）と虹の女神イリス（LED）から付けました。

v6.11.1 の変更（実際の曲 24 曲を録音して分析し、音楽連動を調整しました）
  ・テンポの追跡
    - ハイハットやコードが裏拍で強い部分で、光る拍が裏拍（拍と拍のちょうど間）に張りつくことがあったのを直しました。
      キック（低音）が拍の位置で強いのに裏拍に乗っていれば、半拍ずらします（裏拍にいた時間 平均 15% → 9%）
    - 付点・シャッフルの曲で、テンポをつかむまでに 1 分以上かかることがあったのを直しました（平均 26.6 → 13.7 秒）
  ・光り方
    - パルス・ビートで色替え・ミックス・パーツごとの役割: キックの光が「明るく → 少し暗く → もっと明るく」と段つきで
      立ち上がり、ちかちかして見えていたのを直しました（ちらつき 約半分）
    - ビートで色替え: 拍の間の低音の光を控えめにして、拍の光が目立つようにしました
    - テンポ追従: 拍の頭で帯が明るくなるようにしました
    - きらめき・波紋・テンポ追従・流れる波: 静かな部分では控えめに、サビでは大きく光るようにしました
  ・デバイスの写真: 写真の共有サイトから、製品の写真ではないもの（レビュー動画の 1 コマ・グラフ）を選んでいたのを直しました。
    すでに付いていたものは外して、探し直します

v6.11.0 の変更
  ・自動セットアップ（左のメニュー「自動セットアップ」。これまでの「テスト・調整」）
    - ボタン 1 つで、① まだ測っていないファンの特性を測る → ② CPU で測る → ③ GPU で測る、まで進み、
      目標温度を守れる、いちばん静かなカーブを作ります（約 20〜30 分。結果は確かめてから適用します）
    - GPU の負荷もアプリがかけるようにしました。ゲームやベンチマークを起動する必要はありません
    - 特性を測ったファンは、止まる回転数より少し上に最低回転数を引き上げます（下げることはありません）
    - CPU と GPU の目標温度を別々に決められます。「全プロファイルにまとめて適用」では、静音は +5°C、冷却重視は −5°C で作ります
  ・言葉の整理
    - 「おまかせ調整」は「自動セットアップ」に、ファンごとの「目標温度（おまかせ）」は「目標温度」に、
      「自動キャリブレーション」は「ファンの特性（特性を測る）」に、カーブ画面の「自動で作る…」は「自動セットアップ…」にしました
  ・測定が 1 段もできなかったときに「全開でも届きません（全開で °C）」と出ていたのを直しました
  ・GPU の負荷には Vortice（MIT ライセンス）を使っています。ライセンスは licenses フォルダーにあります

        間違った拍のまま光る時間 6% → 4%、曲が始まってから拍をつかむまで 23 秒 → 13 秒）
    - 曲のテンポを覚えておき、にぎやかな部分で拍を見失っても、同じテンポですぐつかみ直します。
      拍の並びがずっと同じだけずれているときは、ずれを直します
    - ゆっくりした曲（80〜90 BPM くらい）が、倍の速さで光り続けることを減らしました
      （録音した 31 曲で、倍の速さで追っている時間 9.9% → 4.5%、拍と拍の間で光る割合 13.0% → 10.4%）。
      代わりに、150〜160 BPM くらいの速い曲がときどき 1 拍おきに光ります（光るのは拍の上のままです）
    - スネアを、これまでの約 2 倍見つけるようにしました。スネアで光るのも 11 ミリ秒早くなりました
    - Windows の音の形式を 96 kHz・192 kHz などにしていても、44.1 / 48 kHz と同じように拍とスネアをつかみます
      （これまでは、スネアを見落としたり、倍のテンポでつかんだりしていました）
    - 音の出口（オンボード・USB・HDMI / DisplayPort・Bluetooth・仮想デバイス）を見分けて、ライティングの画面に表示します。

    - 「ビートで色替え」: ベル・ピアノなどの高音やメロディでも、ふくらむように光ります。
      ドラムが鳴っている曲では、これまでどおりキック・スネアが主役です。キックを少し強くしました
    - 新しい光り方: 「パーツごとの役割」（低音・中音・高音をゾーンごとに）、固定色のパレット。「きらめき」を分かりやすくしました
    - 消灯（制御は続ける）: トレイと設定から、LED を消したまま、音楽連動などの計算は続けられます
    - 「反応のしかた」に、初期値から変えている値を表示し、「初期値に戻す」で戻せるようにしました
    - グラボの LED の直接書き込みは、確かめた型番だけにしました（ほかのグラボは OpenRGB を通して光らせます）

■ はじめての準備（1 回だけ）
  1. Zeph-Iris-<版>-setup.exe（インストーラー）をダブルクリック →「はい」（管理者権限の確認）
     ・「Windows によって PC が保護されました」と出たら、
       「詳細情報」→「実行」を押してください（個人で作ったアプリで、コード署名の証明書がないため表示されます）
     ・「次へ」→「インストール」で、C:\Program Files\Zeph-Iris に入ります（スタートメニューにも登録されます）
     ・最後の画面で「Zeph-Iris を実行する」にチェックを入れたまま「完了」を押すと、Zeph-Iris が起動します
       （インストーラーは、そのあと消してかまいません）

  2. セットアップウィザードの最初の画面で、ファンを制御するためのドライバー（PawnIO）を確かめます
     ・PawnIO がなければ、自動でインストールを始め、入ったらアプリが自動で起動し直します
       （Windows に付属の winget で入れます。インターネットが必要で、数十秒〜数分かかります。起動し直すと、ウィザードがもう一度開きます）
     ・PC の再起動が必要と出たときは、PC を再起動してから、スタートメニューの Zeph-Iris を起動します
     ・うまくいかないときは、アプリのフォルダ（C:\Program Files\Zeph-Iris）の「1_PawnIO をインストール.bat」を右クリック →
       「管理者として実行」するか、https://pawnio.eu/ からインストーラーを入手して実行してください

  3. 画面の案内どおりに進めます
     ・各ファン端子の「テスト」を押すと 8 秒間だけ全開になります。
       速くなったファンを見て、名前と種類（ファン / ポンプ / 使わない）を付けてください
     ・最後に「静音 / 標準 / パフォーマンス」の 3 つの設定が自動で作られます

■ 安全のための仕組み
  ・温度センサーの値がおかしいときや、温度が上限を超えたときは、ファンを全開にします
  ・一瞬だけ跳ねた値（読み取りエラー）は無視し、固まったセンサーは異常として扱います
  ・アプリが終了・停止したときは、BIOS のファン設定に戻ります
  ・アプリが強制終了・フリーズしたときは、「見張りプロセス」がファンを安全な回転数（70%）にして、
    アプリを自動で起動し直します
    → そのため、タスクマネージャーに Zeph-Iris が 2 つ表示されます（片方は見張り役）
  ・スリープに入るときは BIOS の制御に戻し、復帰したら制御を再開します
  ・GPU などを交換してセンサーが変わると、起動時に新しいセンサーへの置き換えを案内します
    （それまでの間、見つからないセンサーを使うカーブは安全な回転数 60% で回します）
  ・簡易水冷のポンプは 40% 未満にならず、回転が落ちたら全開にして知らせます
  ・設定（config.json）は変更のたびに backups フォルダへ自動でバックアップされ、
    壊れたときは起動時に自動で復旧します
  ・おかしいと思ったら、左下の「一時停止（BIOS に戻す）」を押せば、すぐ BIOS の制御に戻ります

■ 使うのをやめるとき（アンインストール）
  次のどちらかで行います。
  A. Windows の「設定」→「アプリ」→「インストールされているアプリ」→ Zeph-Iris の「…」→「アンインストール」
     ・動いていれば Zeph-Iris を正しく終了し（ファンは BIOS の自動制御に戻ります）、ログオン時の自動起動・
       スマホ監視用のファイアウォールの許可などを消してから、アプリを削除します
     ・設定・ログ・記録も消すかを尋ねます（「いいえ」なら、アプリのフォルダに残します）
  B. 設定 →「安全・バックアップ」→「アンインストール（お片付け）…」
     ・行うことが順番に一覧で出ます。確かめてから「お片付けして終了する」を押してください
       - ファンを BIOS の自動制御に戻したことを確かめます（戻せないときは中止して、何も変えません）
       - ライティングの制御を止め、ログオン時の自動起動・スマホ監視用のファイアウォールの許可などを消します
       - 選んだときだけ: 設定・ログ・記録も消す ／ PawnIO もアンインストールする
         （どちらも、選ばなければ残します。PawnIO は FanControl などほかのソフトも使うことがあります）
     ・閉じるとアプリが終了し、続けてアンインストーラーがアプリを削除します（「インストールされているアプリ」からも消えます）
  ※ トレイの「終了」だけでは、ログオン時の自動起動が残ります
  ※ PawnIO をアンインストールできるのは B だけです


■ うまく動かないとき
  ・「PawnIO（ファン制御用のドライバー）が見つかりません」と出る
    → 設定 →「安全・バックアップ」→「ファン制御用のドライバー（PawnIO）」の「PawnIO をインストール」を押し、
      終わったら「アプリを起動し直す」を押します
      （だめなときは「1_PawnIO をインストール.bat」を管理者として実行して、PC を再起動）
  ・ファンの一覧に何も出ない → マザーボードが未対応の可能性があります
    （そのときは温度・使用率の監視だけになり、ファンには何も書き込みません。BIOS の制御のままです）
  ・動作確認済みの環境（開発に使っている PC。対応機種の一覧ではなく、確かめた例です）:
    Windows 11 Pro・ASRock B860 Steel Legend WiFi（Nuvoton NCT6686D）・Intel Core Ultra 5 245KF・
    PNY GeForce RTX 5070 Ti 16GB ARGB Epic-X OC
    ほかの部品でも、LibreHardwareMonitor（ファン・温度）と OpenRGB（LED）が対応していれば動きますが、
    機種ごとの仕様やセンサーの並びで動きが違うことがあります
    （グラボの LED の直接書き込みは、この型番だけ。ほかのグラボは OpenRGB を通して光らせます）
  ・ASRock A-Tuning / ASUS Armoury Crate / MSI Center などのファン制御ソフトが
    入っていると、ぶつかって回転が安定しません。ファン制御機能を止めるか、
    アンインストールしてください
  ・ログ: アプリのフォルダ（C:\Program Files\Zeph-Iris）の logs フォルダ
  ・設定をおかしくしてしまった → 設定 →「安全・バックアップ」→「バックアップから戻す」


■ アプリのフォルダ（C:\Program Files\Zeph-Iris）にできるもの
  config.json … 設定          backups … 設定の自動バックアップ
  logs        … ログ          data    … 1 分ごとの記録と電力量（最大 180 日）
  records     … 異常の前後の記録（CSV）    reports … AI の回答
  images      … デバイス画面で差し替えた画像
